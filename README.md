# Typing Speed Test ⌨️

A typing practice app starter. The interface is ready; implement the test logic yourself.

## Checklist
- [ ] Select a random passage
- [ ] Highlight correct, incorrect and current characters
- [ ] Start a 60-second timer on first keystroke
- [ ] Calculate WPM, accuracy and errors
- [ ] Finish automatically when time reaches zero
- [ ] Implement New Test and Finish Test
- [ ] Save best WPM in `localStorage`
- [ ] Bonus: difficulty levels and 30-second mode

## Run
Extract the ZIP, open the folder in VS Code, then open `index.html` or use Live Server.

## GitHub
Create a repository named `typing-speed-test`; use `git add .`, `git commit -m "Build Typing Speed Test"`, and `git push`.

## Concepts
DOM rendering, input events, intervals, string comparison, calculations, state and localStorage.
